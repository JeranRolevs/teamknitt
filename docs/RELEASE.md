# teamknitt 0.5.0

- Standalone `teamknitt.engine` runtime, provider adapters, schemas, resources and engine CLI.
  No installed upstream package, CLI or parent checkout is required. Based on Labtune;
  original Goran Mitevski / Pioneertown B.V. credit and legal terms are unchanged.
- One package namespace and console command. Advanced functions use `teamknitt engine`.
  New workspace launchers are `team.py` and `engine.py`, with teamknitt credential-variable names.
- Two approach groups: **Standard** (collaborative intelligence; shared models/member reports)
  and **Complexity** (distributed problem-solving; team dynamics; interactions/coordination).
- Distributed problem-solving is the product terminology; original publication titles and
  historical record bindings remain intact. The two groups are explanatory orientations,
  not an exhaustive partition of research or automatically selected execution modes.
- Bayesian/probabilistic analysis, prior elicitation and their package extra are removed from
  teamknitt. Legacy choices fail explicitly, never silently becoming frequentist analyses.
  Descriptive records and supported count/interval analyses remain; the upstream project is untouched.
- Read-only saved-record compatibility and explicit, backed-up, lock-protected name migration.
  Existing model choices, budgets, brief text and credential files are preserved.
- Fourteen user-selected topology presets remain supported at 1–16 members. No quality score,
  automatic model choice, organizational optimization or budget increase is introduced.

Setup, planning, tests, diagrams and views require no paid provider calls. Private sources,
credentials, trials, results and migration backups remain outside Git and distributions.
