# Meeting facilitator boundary

Use a bounded agenda, input snapshot, participant list, and round/word/call budget. Gather private
initial positions before exposing peers where configured. Deliver recipient-filtered packets;
meetings are not richer communication channels than the selected profile.

Record observations, proposals, objections, minority views, unresolved issues, and the next
eligible test. End when the declared meeting limit or finish condition is reached. Facilitation
is procedural and may rotate. Agreement or a work-allocation vote does not establish scientific
validity. Return scheduling proposals to the controller instead of executing unbudgeted work.
